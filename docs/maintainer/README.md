# For maintainers

These pages are for the person who publishes KassenSturz, not for its users. They give the short version of the release path and the limits of each store; the full details stay in the repository's own documents, which these pages link to.

- [Tagging and publishing a release](01-releasing.md): from a green commit on `main` to the GitHub release, the Snap Store and the Microsoft Store.
- [Why Windows and macOS take extra work](02-platforms.md): what each platform's store and signing rules mean for a small free project.

Only the maintainer tags, approves and publishes (AGENTS.md section 3.2). Agents prepare and explain; they never push a tag or press *Approve and deploy*.
