# KassenSturz: install step log

*Team copy of [INSTALL_LOG.de.md](INSTALL_LOG.de.md), the one handed to testers. For installing at home (card 1), filled in while following the install sheet ([Windows](INSTALL_WINDOWS.en.md), [Ubuntu](INSTALL_UBUNTU.en.md)).*

> **Please, no real data.** Use only the example book in the test. If you still enter your own accounts, amounts, banks or IBANs, that data is recorded and analysed: in the screen and audio recording, in the app's log and in your report. That is why we ask you not to.

**How it works:** the tester installs alone; nobody helps or watches. One line per step of the sheet: the time, whether it worked (yes / with effort / no) and what they saw or didn't understand. Small things count.

**If stuck:** write down where, stop, and send the log to the facilitator. The facilitator gives one hint by e-mail and notes it as a finding.

Steps: Windows 1 to 6 (download page, right file, the warnings, install, developer mode, first start up to the overview). Ubuntu A1 (snap install) and A2 (developer mode), only if way A fails B1 to B5 (Flatpak), then the first start up to the overview.

**At the end:** how long did it take in total? Would you have given up without this sheet, and where? A screenshot of the app's first screen, only if it shows no own data.

The log goes **only to the facilitator** ([report page](REPORT_PAGE.en.md)).
