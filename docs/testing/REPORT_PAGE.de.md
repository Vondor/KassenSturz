# Einen Fehler melden

*Für Testerinnen und Tester. Englische Fassung: [REPORT_PAGE.en.md](REPORT_PAGE.en.md).*

## Wohin damit?

Schicken Sie den ausgefüllten Fragebogen und Ihre Fehlerberichte **direkt und nur an die Testleitung**, auf dem Weg, den sie Ihnen genannt hat (zum Beispiel per E-Mail). Sie brauchen dafür **kein GitHub-Konto**.

- Ihr Bericht wird **nicht veröffentlicht**: nicht im Projekt, nicht in der öffentlichen Fehlerliste, nicht in einer gemeinsamen Ablage.
- Ihr Bericht wird von keinem KI-Werkzeug gelesen, auch dann nicht, wenn die Testleitung sonst damit arbeitet.
- Die Testleitung beschreibt das Problem in eigenen Worten, wenn sie es weitergibt. Ihr Name und Ihre Texte stehen dort nicht.
- Hat Ihr Bericht **echte Daten** (Frage 8 im Fragebogen: „ja“), bleibt er allein bei der Testleitung und wird **nach der Testrunde gelöscht**.

## Was gehört in einen Bericht?

Ein Blatt pro Problem:

| Feld | Was hier hinein gehört |
|---|---|
| Titel | Eine Zeile: was ging schief |
| Karte | Welche Nummer (oder „außerhalb der Karten“) |
| Was ich wollte | Das Ziel, in Ihren Worten |
| Was ich erwartet habe | ____ |
| Was passiert ist | Auch jede Meldung, Wort für Wort |
| Passiert es wieder? | ☐ immer ☐ manchmal ☐ einmal |
| Versionsnummer | Aus dem Fenster „Über KassenSturz“ |
| Computer | Windows oder Ubuntu, Version |
| Bildschirmfoto | Nur, wenn nur Beispiel- oder Testdaten zu sehen sind |
| Protokoll | Aus dem Hinweisband des Entwicklermodus („Protokoll zeigen“), wenn Sie möchten |
| Wie schlimm | ☐ hält mich auf ☐ nervt ☐ Kleinigkeit |
| Echte Daten enthalten? | ☐ nein ☐ ja → dann bleibt der Bericht nur bei der Testleitung und wird gelöscht |

Beschreiben Sie ruhig auch, was Sie **gefühlt** haben („verunsichert“, „genervt“). Das ist oft der wichtigste Teil.

## Für die Testleitung

- Berichte mit echten Daten gehen an keinen Agenten, in keine Datei des Projekts, in kein Issue und in keinen Prompt (D-552). Sie werden nach der Runde gelöscht.
- Berichte ohne echte Daten werden in den Worten des Teams neu geschrieben, bevor daraus ein Eintrag in der Fehlerliste wird. Kein Wortlaut von Testern, keine Bildschirmfotos aus ihren Berichten im Projekt.
