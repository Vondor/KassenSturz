# 1. Was KassenSturz ist, in zwei Minuten

*Diese Seite sagt, wozu KassenSturz gut ist und was es für Sie tut. Fachwörter brauchen Sie nicht.*

KassenSturz ist ein **Haushaltsbuch** für Ihren Computer. Sie halten darin fest, wo Ihr Geld ist (auf dem Girokonto, auf dem Sparkonto, im Portemonnaie) und wohin es geht. Daraus zeigt KassenSturz Ihnen auf einen Blick, **wie Sie dastehen**: wie viel Sie haben, was diesen Monat hereingekommen und hinausgegangen ist und wofür.

## Das Wichtigste

- **Die Übersicht ist die Startseite.** Sobald KassenSturz aufgeht, sehen Sie, wo Sie stehen. Alles andere ist ein Schritt weiter, wenn Sie mehr wollen.
- **Ihre Daten bleiben bei Ihnen.** Das Haushaltsbuch liegt auf Ihrem Computer. Ohne Ihr ausdrückliches Ja wird nichts verschickt. Es gibt keine Werbung und keine Weitergabe.
- **Zahlen stimmen auf den Cent.** KassenSturz rechnet mit genauen Beträgen und rundet nur die Anzeige, nie die Rechnung.
- **Alles lässt sich zurücknehmen.** Mit **Rückgängig** machen Sie die letzte Änderung rückgängig, auch nach einem Neustart.
- **Es verschickt kein Geld.** KassenSturz liest Kontostände und Umsätze, es überweist nie etwas.
- **Die KI-Funktionen sind aus**, bis Sie sie selbst einschalten. Dieses Handbuch beschreibt KassenSturz ohne sie; alles hier klappt ohne KI.

## Die wenigen Wörter, die Sie kennen sollten

| In der App | Gemeint ist |
|---|---|
| **Haushaltsbuch** | alles, was KassenSturz über Ihr Geld weiß, in einer Datei auf Ihrem Computer |
| **Konto** | ein Ort, an dem Ihr Geld liegt: Girokonto, Sparkonto, Bargeld, Kreditkarte |
| **Buchung** | eine einzelne Zahlung oder Gutschrift |
| **Kategorie** | wofür Geld ausgegeben wurde oder woher es kam, zum Beispiel *Lebensmittel* oder *Gehalt* |
| **Umbuchung** | Geld, das Sie zwischen Ihren eigenen Konten bewegen; es zählt weder als Einnahme noch als Ausgabe |
| **Regel** | ein Auftrag an KassenSturz: „Sortiere alles von diesem Namen in diese Kategorie“ |

Eine ausführlichere Liste steht am Ende des Handbuchs (Seite 20).
