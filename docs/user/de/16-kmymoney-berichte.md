# 16. Berichte aus KMyMoney

*Wer von KMyMoney kommt, kann seine gespeicherten Berichte mitnehmen. Diese Seite zeigt, wie.*

## Beim ersten Einlesen

Starten Sie ein Buch aus einer KMyMoney-Datei (Seite 3), kommen deren gespeicherte Berichte als **gespeicherte Ansichten** im Statistik-Baukasten mit. Die letzte Seite listet jeden Bericht unter:

- **Unverändert übernommen**,
- **Mit Änderungen übernommen** (mit dem, was sich geändert hat, in einfachen Worten),
- **Nicht übernommen** (mit dem Grund).

Ein Zeitraum wie „Letzte 30 Tage“ wird zu den Tagen, die er am Tag des Einlesens umfasste; sie stehen daneben.

## Später dazuholen

**Berichte aus einer KMyMoney-Datei hinzufügen…** (Statistik-Baukasten, Gespeicherte Ansichten) holt die Berichte einer KMyMoney-Datei in das geöffnete Buch, so oft Sie möchten, zum Beispiel solange Sie KMyMoney noch nebenher benutzen. Sonst kommt nichts aus der Datei herein. Konten und Kategorien werden nach ihrem Namen gefunden; was Ihrem Buch fehlt, wird weggelassen und genannt. Verliert eine Ansicht ihren ganzen Filter, sagt KassenSturz, dass sie jetzt mehr zeigt als in KMyMoney.

**Bevor etwas geschrieben wird**, zeigt eine Seite jeden Bericht:

- **Neu in dieser Datei** (angekreuzt; nehmen Sie weg, was Sie nicht wollen),
- **Anders als Ihre Ansicht** (Ihre Ansicht bleibt, es sei denn, Sie kreuzen „Durch die Version aus KMyMoney ersetzen“ an),
- **Schon da**,
- **Nicht übernommen**,
- Ansichten, deren Bericht **nicht mehr in der Datei** steht (sie bleiben).

**Berichte hinzufügen** schreibt, was angekreuzt ist; einmal **Rückgängig** nimmt alles zurück. Gelöscht wird dabei nie etwas. Die Datei selbst wird nur gelesen.

**Wenn etwas anders aussieht:** Hat ein Bericht kein Gegenstück in KassenSturz, steht er unter „Nicht übernommen“ mit dem Grund; das ist keine Fehlermeldung.
