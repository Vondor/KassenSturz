# 19. Wenn etwas nicht klappt

*Fast jede Meldung sagt, was passiert ist und was Sie tun können. Diese Seite sammelt die häufigsten und sagt, wie Sie ein Problem melden.*

## Meldungen

**Lesen Sie die Meldung ganz.** Meistens steht die Lösung darin. Einige häufige:

| Meldung | Was tun |
|---|---|
| „Dieses Buch ist auf … geöffnet“ | Das Buch ist an einem anderen Ort offen (oder KassenSturz ist abgestürzt). Schließen Sie es dort und wählen **Erneut versuchen**; oder **Trotzdem öffnen**, wenn Sie sicher sind, dass es nirgends offen ist. |
| „Das ist kein Betrag“ | Tippen Sie ihn so, wie die Meldung ihn zeigt, in Deutschland also `1.234,56`. |
| „… hat Buchungen, deshalb kann sie nicht gelöscht werden“ | Ordnen Sie die Buchungen zuerst einer anderen Kategorie zu (Seite 6). |
| „Keines Ihrer Budgets deckt diese Tage ab“ | Wählen Sie einen Zeitraum, in dem ein Budget läuft (Seite 13). |
| „Der Betrag … hat mehr Dezimalstellen“ | KassenSturz rundet nie von selbst. Lassen Sie die überzähligen Stellen weg. |
| Die Bank sagt „PIN falsch“ | KassenSturz vergisst sie sofort und fragt einmal nach. Prüfen Sie sie beim Bank-Login, bevor Sie es noch einmal versuchen (Seite 11). |
| Ein Hinweis, dass die Bankverbindung fehlt | Das Flatpak und die Windows-Version bringen sie mit; bei anderen Paketen sagt die Meldung, was Sie installieren. Dateien einlesen geht immer (Seite 10). |

## Ein Buch öffnet sich nicht

- Ist das Buch von einer **älteren Entwicklungsversion**, öffnet es sich in einer neueren möglicherweise nicht. Öffnen Sie es dann in der alten Version und speichern Sie das ganze Buch (Seite 17), oder legen Sie ein neues an.
- KassenSturz verändert ein Buch nur, wenn es vorher eine Sicherung angelegt hat (**Einstellungen › Sicherungen**).
- Liegt das Buch auf einem **Netzlaufwerk**, warnt KassenSturz; ein Buch ist am besten auf dem eigenen Computer.

## Ein Problem melden

Schreiben Sie auf, **was Sie tun wollten, was Sie erwartet haben und was passiert ist**, mit der Versionsnummer aus **Über KassenSturz**. Tragen Sie in Bildschirmfotos, die Sie weitergeben, **keine echten Kontodaten** ein; benutzen Sie ein Beispielbuch und erfundene Zahlen.

Ein Protokoll (nur während der Testzeit): Starten Sie KassenSturz einmal im **Entwicklermodus**, wie im Installationsblatt beschrieben (Seite 2). Das Protokoll enthält keine Beträge, Namen oder Passwörter.

KassenSturz ist ein Werkzeug zum Führen Ihres Haushaltsbuchs. Es gibt **keine Steuer-, Rechts- oder Anlageberatung**.
