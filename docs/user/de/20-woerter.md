# 20. Wörter in der App, erklärt

*Die Wörter, die Ihnen in KassenSturz begegnen, in einfachen Sätzen, alphabetisch.*

| Wort | Bedeutung |
|---|---|
| **Angezeigter Name** | Der Name, der bei einer Buchung als *Von* oder *An* steht. Er beginnt als der Name des Zahlungspartners; eine Regel kann ihn durch einen klareren ersetzen. |
| **Anfangsbestand** | Wie viel an dem Tag auf einem Konto war, den Sie beim Anlegen genannt haben, meist heute. |
| **Aufteilen** | Eine Buchung in Teile zerlegen, je nachdem wofür das Geld war (Seite 7). |
| **Bankzugang** | Ihr Zugang zu einer Bank, um Buchungen abzurufen: Anmeldename und PIN, einmal je Bank eingerichtet (Seite 11). |
| **Budget** | Ein Betrag, den Sie für eine Ausgabenkategorie ausgeben möchten. Es zeigt nur, wie Ihre Ausgaben dazu stehen (Seite 13). |
| **Buchung** | Eine einzelne Zahlung oder Gutschrift. |
| **Dashboard** | Eine Seite, die Sie aus Diagrammen, Tabellen und Zahlen zusammenstellen. Die Übersicht ist das erste (Seite 4). |
| **Geld rein / Geld raus** | Was über Einnahmen- und Ausgabenkategorien hereinkam und hinausging. Umbuchungen und Anfangsbestände zählen nicht. |
| **Haushaltsbuch** | Alles, was KassenSturz über Ihr Geld weiß, in einer Datei auf Ihrem Computer. |
| **Kategorie** | Wofür Geld ausgegeben wurde oder woher es kam (Seite 6). |
| **Kontostand** | Wie viel jetzt auf einem Konto ist. Bei einer Schuld steht „Sie schulden …“. |
| **Mit der Bank abgleichen** | Tippen, was Ihre Bank als Stand nennt; KassenSturz sagt, ob es dasselbe hat, und ändert nie von allein etwas (Seite 5). |
| **Muster (fortgeschritten)** | Eine genauere Art, in einer Regel Text zu finden. Nie nötig. |
| **Noch nicht zugeordnet** | Eine Buchung ohne Kategorie. Zählt in keiner Kategoriesumme. |
| **Regel** | Ein Auftrag, Buchungen von selbst zu sortieren (Seite 12). |
| **Rückgängig / Wiederholen** | Die letzte Änderung zurücknehmen oder noch einmal ausführen (Seite 9). |
| **Sicherung** | Eine vollständige Kopie des Buches, die KassenSturz vor einer Anpassung an eine neue Version selbst anlegt. |
| **TAN** | Eine einmalige Nummer, die die Bank zur Bestätigung verlangt. KassenSturz sendet sie einmal und behält sie nie. |
| **Teil / Teilbetrag** | Ein Stück einer aufgeteilten Buchung. |
| **Umbuchung** | Geld zwischen zwei eigenen Konten. Weder Einnahme noch Ausgabe (Seite 8). |
| **Umsätze** | Die Liste der Buchungen eines Kontos. |
| **Verlauf** | Die Liste der Änderungen am Buch, damit jede rückgängig gemacht werden kann (Seite 9). |
| **Von der Bank noch nicht gebucht** | Ein Eintrag, den die Bank nennt, aber noch nicht gebucht hat. Der Import lässt ihn aus. |
| **Wechselkurs** | Wie viel eine Währung in einer anderen kostet, an einem Tag. Tragen Sie von Hand ein. |
| **Wertstellung** | Der Tag, ab dem Geld für Zinsen zählt, wie die Bank ihn liefert. Steht nur in den Einzelheiten. |
| **Zahlungspartner** | Die andere Seite einer Buchung: von wem Sie Geld erhalten oder an wen Sie es zahlen. |
