## So lesen Sie dieses Handbuch

- Fett gedruckt sind **Beschriftungen aus der App**, genau so, wie Sie sie auf dem Bildschirm sehen.
- Jede Seite beginnt mit einem Satz, wofür sie da ist, und endet mit „Wenn etwas anders aussieht“.
- Die Bildschirmfotos stammen aus den ausgedachten Beispielbüchern. Echte Konten, Namen oder Banken kommen nirgends vor.
- KassenSturz gibt keine Steuer-, Rechts- oder Anlageberatung.
