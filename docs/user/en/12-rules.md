# 12. Rules: the app sorts for you

*A Rule tells KassenSturz: "Sort everything from this name into this category." This page shows how to make Rules, apply them and take them back.*

## What Rules are for

With **Rules** in the menu, KassenSturz sorts new transactions by itself, for example everything from the supermarket into *Groceries*. This saves handwork, above all after an import.

## KassenSturz suggests Rules

When you have sorted the same other party into the same category by hand **three times**, KassenSturz asks: "Want KassenSturz to do it for you from now on?" **Create a Rule** opens the Rule editor, already filled in; with **No, thanks** the question isn't asked again. This is simple counting, not AI.

On a transaction's page, **Create a Rule from this transaction…** does the same whenever you want.

## Making a Rule

1. **Rules** in the menu, then **Add a Rule**.
2. Give the Rule a **name**.
3. Under **When a transaction fits**, set one or more conditions, for example: the **Other party** contains a word. While you type, you see **how many transactions** fit.
4. Under **Then**, say what happens: sort into a category. A Rule can also replace the **Name shown**, for example with a clear "Supermarket" instead of a jumble such as "SUPERSTORE 1234 THANK YOU".
5. **Add a Rule** saves it.

**Use a pattern (advanced)** allows more exact conditions. You never need it; how it works is on the help page **Help: patterns, formulas and charts** (under a pattern condition: **More about patterns**) and on page 15.

## Order and Rules inside Rules

- The **first Rule that fits** in the list applies. Change the order with the arrows.
- A Rule inside another (**Add a Rule inside this one…**) is only checked when the Rule around it has already fitted. If it fits too, it refines the result.
- A Rule sorts **only transactions without a category**. What you sorted yourself stays untouched.

## Applying Rules to older transactions

A new Rule at first only sorts transactions that come in **later**. For transactions already in the book:

- **Apply all Rules…** at the top of the Rules page,
- **Apply now…** on one Rule,
- **Add and apply now…** in the Rule editor.

A window first shows **how many transactions will be sorted**, which stay as they are and why, and the newest five as they will look afterwards. Only the button with the number (for example **Sort 3 transactions**) changes anything. **Cancel** changes nothing.

Normally only transactions without a category are sorted. With **Also sort again what Rules sorted before**, transactions a Rule sorted earlier and that you haven't touched since are sorted again too. **What you sorted or changed yourself always stays untouched.** One **Undo** takes it all back.

**If something looks different:** if a transaction isn't sorted, it may already have a category, or a Rule higher up got it first. The window shown when applying names the reason.
