# 20. Words in the app, explained

*The words you meet in KassenSturz, in plain sentences, in alphabetical order.*

| Word | Meaning |
|---|---|
| **Backup** | A complete copy of the book that KassenSturz makes by itself before it adapts the book to a new version. |
| **Balance** | How much is in an account now. For a debt it reads "You owe …". |
| **Bank login** | Your access to a bank, to fetch transactions: login name and PIN, set up once per bank (page 11). |
| **Book** (household book) | Everything KassenSturz knows about your money, in one file on your computer. |
| **Break down** | Splitting a transaction into parts, by what the money was for (page 7). |
| **Budget** | An amount you want to spend on a spending category. It only shows how your spending compares with it (page 13). |
| **Category** | What money was spent on or where it came from (page 6). |
| **Check against my bank** | Typing what your bank gives as the balance; KassenSturz says whether it has the same, and never changes anything by itself (page 5). |
| **Dashboard** | A page you put together from charts, tables and figures. The overview is the first one (page 4). |
| **Exchange rate** | How much one currency costs in another, on a given day. You enter it by hand. |
| **History** | The list of changes to the book, so each one can be undone (page 9). |
| **Money in / Money out** | What came in through money-in categories and went out through spending categories. Transfers and starting balances don't count. |
| **Name shown** | The name a transaction shows as *From* or *To*. It starts as the other party's name; a Rule can replace it with a clearer one. |
| **Not booked by your bank yet** | An entry the bank lists but hasn't booked yet. The import leaves it out. |
| **Not sorted yet** | A transaction without a category. It counts in no category's total. |
| **Other party** | The other side of a transaction: who you receive money from or who you pay it to. |
| **Part** | One piece of a transaction that was broken down. |
| **Rule** | An instruction to sort transactions by themselves (page 12). |
| **Starting balance** | How much was in an account on the day you named when you added it, usually today. |
| **TAN** | A one-time number the bank asks for to confirm something. KassenSturz sends it once and never keeps it. |
| **Transaction** | One single payment or deposit. |
| **Transfer** | Money between two of your own accounts. Neither money in nor money out (page 8). |
| **Undo / Redo** | Taking back the last change, or making it again (page 9). |
| **Use a pattern (advanced)** | A more exact way of finding text in a Rule. Never needed. |
| **Value date** | The day from which money counts for interest, as the bank delivers it. Only shown in the details. |
